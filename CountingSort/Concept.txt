Counting sort :
counting sort is a non comparison based sorting algorithm. Instead of comparing elements like Mergesort or Bubblesort, it counts how many times each element appears and then reconstructs the sorted array.
- It works effeciently when the numbers are integers and range of value is small.

--> WHY DO WE NEED COUNTING SORT?
- Many algorithms like Bubblesort, Mergesort, Quicksort compare elements and require many comparions.
- Countingsort avoids comparisons completely, Instead it asks "How many times does each number appear?"
- This makes it much faster when the range of value is small.


--> CHARACTERISTICS OF COUNTINGSORT :
- Non comparison based algorithm.
- Stable sorting algorithm ( when implemented using cumulative counts(prefixsum))
- Works on integer data.
- Very fast for small ranges and not stable for large ranges.
- Uses extra memory
- Linear sorting algorithm
